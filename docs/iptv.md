# 播放 IPTV

IPTV 就是通过网络看的电视直播。TinyPlay 可以读取 IPTV 播放列表，把频道放到手机上浏览，再让接电视的电脑播放；切换频道、暂停和跳回直播都还是同一套遥控器。

![TinyPlay 手机 IPTV 频道界面](/screenshot-iptv.png)

## 怎么使用

1. 打开 TinyPlay 的“设置”，点击“添加内容源”。
2. 选择“IPTV”，输入 M3U 或 M3U8 播放列表地址并保存。
3. 回到“媒体库”，选择频道分类，点击频道开始播放。

## 播放卡顿怎么办

不同 IPTV 播放列表的可用性与稳定性差异较大。若出现卡顿、频道无法连接或画质不稳定，原因通常来自播放列表本身、频道源或网络线路，而非 TinyPlay 客户端。

TinyPlay 负责解析播放列表并完成播放；若源端质量不佳，无法通过客户端侧将其变为稳定信号。
