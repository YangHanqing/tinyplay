# 手机投屏（DLNA）

DLNA 可以理解成一种通用的投屏协议。手机上的播放器找到播放设备后，就可以把视频、音乐或照片投过去。

哔哩哔哩、爱奇艺、腾讯视频、优酷等常见播放器里，通常都能找到“投屏”按钮。

![手机选择 TinyPlay 作为 DLNA 接收设备](/screenshot-dlna.png)

## 用 TinyPlay 接收投屏

Windows 和 macOS 默认不能直接接收 DLNA 投屏。TinyPlay 集成了 DLNA 接收器，安装并运行后，这台接电视的电脑就可以出现在手机播放器的投屏设备列表里。

使用时：

1. 确认手机和运行 TinyPlay 的电脑连接的是同一个局域网。
2. 在手机播放器中点击“投屏”，选择运行 TinyPlay 的电脑。
3. 选择视频，电脑会通过电视播放。

## 倍速播放

DLNA 投屏后，官方 App 通常不支持直接调节倍速。需要调整播放速度时，可返回 TinyPlay 手机端的「遥控器」页面，在其中选择倍速。

## 注意事项

DLNA 投屏仅传输音视频内容本身，**不支持弹幕**，也**不支持受 DRM（数字版权管理）保护的内容**。平台若对片源启用了此类保护，投屏往往无法正常开始播放，或只能播放未受保护的部分内容。

如需观看带弹幕的内容，或播放多数受版权保护机制限制的在线视频，建议改用 [网页控制](/website)：在接电视的电脑上打开对应网站，再通过手机遥控，即可在多数场景下保留弹幕，并沿用电脑端已登录账号的正常观看权限。
