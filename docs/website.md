# 网页控制

> **平台说明：** 网页控制仅支持 **Windows** 与 **macOS**；**Apple TV 版本不支持**。<br>
> 受平台规则所限，内嵌完整网页浏览能力的应用通常难以通过 App Store 审核，因此该能力仅在电脑端提供。

网页控制可以在接电视的电脑上打开常用视频网站，再用手机遥控。你不必坐到电脑前操作键鼠，也能选片、播放和调节进度。

![手机控制电脑端在线视频播放](/screenshot-online-video.png)

可直接选用的网站包括哔哩哔哩、爱奇艺、腾讯视频、优酷和抖音精选。你还可以自行添加常用网址；这些网址会保存在这台 TinyPlay 电脑上，同一局域网内连接它的手机都能看到。

请在电脑端自行完成登录，并遵守各平台关于账号、会员、地区与终端的使用规则。

## 如何使用

1. 在手机的「网址库」中选择要打开的网站。
2. 网站会在接电视的电脑上打开。
3. 回到手机的「遥控器」，即可控制播放、快退、快进和全屏。

个人添加的网址可使用通用遥控，以及「选择页面元素」来点按网页上的按钮。站点专用操作仅对内置支持的网站生效。

## 使用说明

网页控制的目的，是把电脑上的网页操作，变成更适合沙发场景的手机遥控。它不改变各平台本身的权限边界：能看什么、是否有广告，仍取决于你在电脑端登录的账号与订阅。

各视频网站若改版，个别控制可能需要后续适配。TinyPlay 不提供去广告、跳过登录、规避会员或终端限制、地区访问绕过，也不提供下载、录制或转播功能。
