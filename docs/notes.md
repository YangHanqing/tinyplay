# 注意事项

## 屏保与电视

TinyPlay 的屏保只做一件事：避免电视长时间停在同一幅画面上，降低烧屏风险。

建议同时启用 Windows 或 macOS 自己的屏保，并把电脑设为不自动休眠；平时用遥控器开关电视屏幕即可。macOS 自带的屏保已经很好看，也很适合客厅场景。

## 设备配对与安全

为避免局域网中的任意设备直接操控电脑，新手机需要先配对：扫 TinyPlay 窗口里的二维码即可；手动输入地址时，在电脑上确认一次即可。

TinyPlay 的控制页面只面向局域网设备，当前实现不支持通过互联网远程控制。请不要用端口映射、反向代理或网络隧道绕过这一限制；手机与电脑保持在自己信任的家庭网络中即可。
