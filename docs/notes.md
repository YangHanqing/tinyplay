# 注意事项

## 屏保机制

TinyPlay 的屏保很简单，主要目的是避免电视长时间停在同一幅画面上，减少烧屏风险。

当视频暂停超过五分钟后，屏保会出现。它会把当前影片的海报作为背景并压暗，同时显示时间、日期和影片名称。背景图片大约每分钟更换一次。

继续播放、按下遥控器上的控制按钮，或停止播放后，屏保就会消失，回到正常画面。

它不是一个完整的系统屏保，也不是为了省电或保护隐私设计的。目前它只做最重要的一件事：避免电视长时间显示同一幅静止画面。

## 设备配对

每台手机都要先和电脑配对一次，才能进行控制。在此之前，TinyPlay 不会响应任何请求。

正常的方式是扫 TinyPlay 窗口里的二维码：二维码里带着一串很长的随机码，扫完即完成配对，不需要再确认。如果你是在浏览器里手动输入电脑地址，TinyPlay 会请你在电脑上确认——手机上会显示四位数字，电脑窗口会问是否同意与这个数字配对，点“同意”即可。

如果有设备反复提交错误的配对码，二维码会自动停用，窗口里也会说明原因。点窗口里的**换一个二维码**就能用新的随机码重新开放。整个过程中已配对的手机照常可用——别人无法把你自己关在门外。

配对是长期有效的。建议把遥控器添加到手机主屏幕，这样配对不容易丢失：否则 iOS Safari 大约一周不访问就会清掉网站数据，手机需要重新扫码。窗口里的**全部解除**会一次性作废所有手机并更换二维码，手机丢失或借出过就用它。

## 安全提醒

TinyPlay 是按家庭局域网使用来设计的。配对可以阻止同一网络里的其他设备控制这台电脑，但连接本身是明文 HTTP，也没有账号体系，所以仍然不适合直接暴露到公网。

请不要把 TinyPlay 运行时给手机打开的控制页面暴露到公网，也不要通过端口映射、反向代理或网络隧道直接开放给互联网。

这里说的是 TinyPlay 在电脑上运行的控制页面，不是 GitHub Pages 上的产品介绍网站。日常使用时，让手机和电脑保持在自己信任的家庭局域网中即可。

## 网页服务使用边界

网页控制只在用户自己的 Windows 或 macOS 电脑上操作已打开的网站。请自行登录，并遵守网站关于账号、会员、地区和终端使用的规则。

TinyPlay 不提供 VPN、代理或地区访问绕过，也不提供去广告、会员或终端限制规避、下载、录制、内容转播或流地址导出功能。服务提供方调整网页、会员或终端规则后，以其规则为准。
